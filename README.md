I built a CPU Scheduling Simulator using Python and Streamlit to understand and visualize how different CPU scheduling algorithms work.

 Purpose

The main purpose of this project is to:

Learn and compare different CPU scheduling algorithms
Visualize process execution using Gantt charts
Analyze performance using metrics like Waiting Time and Turnaround Time
Understand which algorithm performs best under different conditions

Files
app.py – User interface
algorithms.py – Scheduling logic
visualizations.py – Gantt charts and graphs
export_utils.py – Export results
requirements.txt – Dependencies
